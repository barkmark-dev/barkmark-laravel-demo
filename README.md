# Barkmark Laravel Demo

Laravel demo app for Barkmark and `barkmark-laravel-blade`.

This repo exists to show the format in motion: real `.bark.md` content, the Blade package, and frontend-defined layouts/components.

## Boundary

- Demonstrate the package.
- Keep demo content readable.
- Keep reusable package behavior in `barkmark-laravel-blade`.
- Keep format decisions in `barkmark-spec`.
